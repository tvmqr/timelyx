# Timelyx — SaaS Landing Page

A modern, fully responsive SaaS landing page built with pure HTML, CSS and vanilla JavaScript.  
No frameworks, no libraries — just clean, maintainable code written from scratch.

My first project with JavaScript. Every interactive element — modal, burger menu, form validation, tabs, filters, pricing toggle, FAQ accordion — is hand-written DOM manipulation.  
Built 1:1 from a Figma design.

---

## 🛠️ Tech Stack

- **HTML5** – Semantic markup  
- **CSS3** – Flexbox, Grid, CSS Variables, BEM naming  
- **Vanilla JavaScript** – DOM, events, classList, dataset, closest  
- **Responsive design** – desktop-first, three breakpoints (1199 / 767)  
- **Google Fonts** – Barlow, Inter, Plus Jakarta Sans  
- **No dependencies** – no jQuery, no React, no build step  
- **Formspree** – functional email subscribe forms without backend  

---

## ✨ Key Highlights

- 🧠 **Reusable logic** – one `setupEmailForm()` handles both email forms (hero + newsletter) via `form.querySelector`.  
- 🪟 **Modal "Get a Demo"** – open/close, Escape key, click-outside-to-close.  
- 🍔 **Burger menu** – animated toggle with `aria-expanded`.  
- 📬 **Email validation** – `checkValidity`, success state with animation, auto-reset after 2s.  
- 🔍 **Feature filtering** – filter cards by `data-category` with smooth fade-in.  
- 🗂 **Tabs** – switch between benefit panels without background flicker.  
- 💰 **Pricing toggle** – Month/Year switch with animated price swap via `data-month` / `data-year`.  
- ❓ **FAQ accordion** – single-open behavior with icon rotation and `aria-expanded`.  
- 📬 **Working email forms** – client-side validation + real submission via Formspree, success state with animation, auto-reset after 2s.  
- 📱 **Fully responsive** – looks great on every screen, from mobile to 4K.  
- ♿ **Accessibility** – ARIA states, semantic buttons, hidden labels.  
- ⚡ **No frameworks, no bloat** – just solid HTML, CSS and JS.
